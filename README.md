# Campus Lost & Found

A web application that allows students to report and find lost items
within the campus.

## Features

- User registration and login
- Report lost items
- Report found items
- Search for items
- Submit claims
- Mark items as resolved

## Technologies

- React
- Node.js
- Express.js
- MongoDB

## Installation

1. Clone the repository
2. Install dependencies
3. Start the development server

## How to Run

```bash
npm install
npm run dev
